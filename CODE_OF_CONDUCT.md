# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By taking part in this project (issues, pull requests, discussions and any other project space) you agree to follow it.

In short: be respectful and welcoming, accept constructive criticism, and focus on what is best for the community. Harassment, insults, personal or political attacks and publishing other people's private information are not acceptable.

## Reporting

Please report unacceptable behaviour privately to the project maintainers, using the contact details on the maintainer's GitHub profile. Do not use public issues for this. The maintainers review every report and treat it confidentially.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this Code of Conduct, and may temporarily or permanently ban contributors, following the enforcement guidelines of the Contributor Covenant 2.1.
